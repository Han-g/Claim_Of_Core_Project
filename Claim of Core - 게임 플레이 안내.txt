Claim of Core - 게임 플레이 안내
================================

[시작 방법]
1. 서버를 먼저 실행합니다.
2. 클라이언트를 실행한 뒤 로그인 화면에서 회원가입 또는 로그인을 선택합니다.
3. 로그인에 성공하면 게임에 입장합니다.

[로그인 계정]
이 프로젝트에 기본 로그인 계정은 다음과 같습니다.
admin / admin
admin1 / admin1
admin2 / admin2
admin3 / admin3
admin4 / admin4
admin5 / admin5

필요하다면 로그인 화면에서 회원가입으로 만든 계정을 사용하세요.
아이디: [회원가입한 아이디 입력]
비밀번호: [회원가입 시 설정한 비밀번호 입력]
회원가입 규칙
- 아이디: 영문으로 시작하는 영문/숫자 4~12자
- 비밀번호: 영문/숫자 4~12자
- 아이디에는 admin, gm, master, manager, system, test 문자열을 사용할 수 없습니다.

[기본 조작 키]
W / A / S / D       이동
마우스 이동          시점/카메라 조작
마우스 왼쪽 버튼     공격
마우스 오른쪽 버튼   조준
Space Bar            점프
F                    주변 아이템 줍기 또는 장착
G                    현재 장착 아이템 내려놓기
V                    덩굴 상호작용
C                    역할 스킬 사용

[사망/관전 중 조작]
Q                    이전 관전 대상 선택
E                    다음 관전 대상 선택
Space Bar            선택한 관전 대상 확정

[플레이 흐름]
1. 이동하며 주변 아이템을 F 키로 획득합니다.
2. 마우스 왼쪽 버튼으로 공격합니다.
3. 역할에 맞는 스킬을 C 키로 사용합니다.
4. 사망하면 Q/E로 관전 대상을 고르고 Space Bar로 확정합니다.
참고: G 키의 아이템 드롭 기능은 현재 C++ 입력 바인딩에 남아 있습니다.
      아이템 드롭을 제거한 빌드에서는 G 키가 동작하지 않을 수 있습니다.
